# Models and evidence handling

The recorded run uses [FLAN-T5-small](https://huggingface.co/google/flan-t5-small), [all-MiniLM-L6-v2](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2), and [MS MARCO TinyBERT L2](https://huggingface.co/cross-encoder/ms-marco-TinyBERT-L2-v2). Their maintainers label each model Apache 2.0. `models.lock.json` records immutable revisions and hashes. Weights stay local. Models load with `local_files_only=True` and safetensors; no remote custom code is enabled.

The installed PyTorch wheel is CPU-only. The machine has an RTX 4060, but the reported measurements use CPU execution. CUDA throughput is unmeasured. Four CPU threads are fixed for this run; no thread setting was selected using held-out labels.

Retrieved text can contain instructions, false claims, or forged source labels. The prompt says that evidence is untrusted quoted data and asks the generator to ignore instructions within it. Citation IDs come from the host application's mapping, not from text generated by the model. The model has no filesystem, shell, network, or tool interface. Its output is returned as text.

These controls limit what an injected answer can do; they do not guarantee that its content follows the question or supporting evidence. Treat generated answers as untrusted. Source-label validity, lexical overlap, and entailment are separate checks. The manual review evaluates whether each short answer, interpreted as an answer to its question, is supported by the actual cited window. A comparison answer needs evidence for both sides. Evidence about an unrelated person does not support an answer even if the answer words occur in it.

The experiment includes no production deployment or automated action based on generated answers. Stronger content-level injection defenses and an independent support verifier remain future work.

Three separately recorded synthetic probes check a clean fact, an instruction injected into that fact, and a question with missing evidence. All three returned the expected answer or abstention under the CLI's fixed overlap threshold of 1.0. This threshold differs from the development-selected benchmark threshold. The probe report is an engineering example and provides no estimate of adversarial reliability.
