# Study design

The primary endpoint is response-level agreement with RAGTruth's human hallucination spans. The positive class is an answer with one or more original annotated spans. A span marked `implicit_true` remains positive: a true assertion can lack evidence support. Original conflict, baseless-information, intensity, quality and annotation metadata remain in local records. No independent factual-correctness, relevance or citation-support labels are inferred from their absence.

RAGTruth is pinned to `c103204b9ce28d6bbad859304bf30de72b8ed8fe`. The release contains 17,790 responses from 2,965 sources, including 15,090 official training and 2,700 official test responses. All six responses from a source stay together. Exact duplicate source evidence is excluded before sampling. With seed 58021, each of three task categories contributes 12 development, eight validation and 30 test sources. The study uses 216 development, 144 validation and 540 official-test responses. This is a sampled test study, not the full published benchmark. Related passages can still recur within different source instances; exact source deduplication does not establish semantic document independence.

The full release is loaded for schema, span-offset and source-separation checks. Aggregate test label counts are recorded during preparation, before freezing; this is not a blind annotation vault. Selection code receives development/validation predictions only and never uses test errors, scores or labels to choose thresholds or models. The initial task-balanced 18-response development pilot checks loading, label order, prompt behavior and resource feasibility. Its results remain in `reports/pilot.json`. It motivated a stronger NLI comparator, affirmative prompt wording, mean sentence aggregation and score-quantile threshold candidates. These choices precede the held-out study. No final model choice uses test labels.

Development source groups are hash-ordered and divided into 24 fit and 12 selection groups. Threshold candidates combine a fixed grid and 21 empirical fit-score quantiles. Calibration uses logistic regression on fit groups only. Selection maximizes macro-F1 on selection groups. An ensemble is eligible only if its selection macro-F1 exceeds the best single approach by more than 0.01. Validation diagnoses the choice and does not change it. Model hashes, study configuration, partition hashes, coefficients, thresholds and source identity are frozen before held-out inference. Resuming the test verifies this identity.

The supervised baseline fits response unigram/bigram TF-IDF and three scalar overlap/length features using otherwise unused official training sources. Protected source IDs, exact evidence and exact response duplicates are excluded. It receives no generator identity. This is a trained linear classifier, not neural fine-tuning, and may learn stylistic or task priors rather than support verification.

NLI compares the whole answer or offset-preserving sentence units against up to three lexical-ranked evidence windows of 180 words with a 120-word stride. Pairs are tokenized to 512 tokens with explicit truncation. The highest entailment window supplies each unit's support score. Response aggregation uses maximum or mean unsupported probability. Sentence units can contain multiple factual claims; punctuation splitting can also fragment abbreviations and decimal numbers. Original span overlap supplies sentence diagnostics; it does not create independent atomic-claim annotation or establish span localization performance.

Qwen uses the pinned non-thinking chat template in float16 and scores single-token Yes versus No logits, normalized over those two choices. The affirmative rubric reverses the probability. These are conditional choice scores, not calibrated probabilities of human correctness. Evidence is limited to the first 2,400 tokenizer tokens; the complete answer and rubric remain. BGE uses normalized CLS embeddings against selected windows. Similarity, lexical overlap, exact matching and token F1 against context are weak support proxies. Context is not a reference answer, so those scores must not be called factual answer correctness. Model families receive different evidence selection and input limits. Comparisons therefore describe complete evaluator configurations and do not isolate a causal effect of model size or architecture.

The main results include positive-class precision, recall and F1; macro-F1; accuracy; balanced accuracy; confusion matrices; kappa; MCC; ROC-AUC; average precision; Brier score; and equal-width 10-bin calibration error. Brier and calibration measures describe numeric score reliability; only the logistic outputs are explicitly fitted probabilities. Paired macro-F1 intervals resample complete source groups with 2,000 replicates. Intervals are pointwise and exploratory comparisons have no multiplicity correction. The selected system is fixed in advance. Selective curves report accuracy with coverage; they do not establish a deployment guarantee.

Bias diagnostics use a prespecified 30-response task-balanced test subset. Repetition, model-name attribution, instruction injection, irrelevant evidence, half-context truncation and evidence-line reversal measure score and decision sensitivity. Perturbed evidence is not assigned the unchanged human label. Repeated evaluation forces two uncached passes. Pairwise support ordering uses up to 30 source groups containing one zero-span and one positive-span response, evaluates both orderings, and reports order consistency. This is derived evidence-support preference, not a human stylistic-preference benchmark. Self-preference cannot be established because the evaluated RAGTruth generators differ from the local judges.

RAGBench TechQA is a complementary transfer diagnostic with GPT-generated annotations. Its adherence task and annotation origin differ from human span annotation. The first 120 official test response rows sorted lexically by question ID are evaluated with the original frozen thresholds and weights. These comprise 60 question IDs and evidence groups, with two generated responses each. Transfer agreement cannot be reported as independent human accuracy. No paid APIs are used.

Earlier project aggregate findings motivate this study: lexical citation matching did not establish attribution, strict verification reduced coverage, extra retrieved evidence did not consistently improve answers, and embeddings could confuse incompatible answers. Earlier assistant-authored case reviews are excluded from the reference labels. Previous raw outputs are not necessary to reproduce this study.

Prometheus and 4B generators are deferred in this bounded study. A 4B unquantized model would leave little working room in 8 GB VRAM, while quantized inference would add a different runtime and a separate validation burden. The specialized comparison uses two NLI cross-encoders. This does not answer whether a large specialized generative judge would improve results. Ragas is not run because its usual model-backed configuration would introduce additional evaluators beyond this local study. No numerical equivalence to Ragas is claimed.

The stronger NLI tokenizer is converted from its SentencePiece model to the fast tokenizer. Transformers warns that byte-fallback behavior differs; this study does not compare slow and fast tokenization for rare characters. NLI hypotheses contain response text without the question, so short context-dependent answers can be difficult to interpret. These implementation limits remain part of the measured configurations.

The recorded package inventory contains no bitsandbytes, llama-cpp-python, auto-gptq, autoawq or Accelerate distribution. Quantized larger-model inference would require installing and validating another runtime. The study uses the existing Transformers/CUDA stack and records the resulting limits.

After freezing, a descriptive comparison also uses original RAGBench columns for precomputed Ragas faithfulness, TruLens groundedness and GPT-3 adherence. Each comparator is aligned to the exact same available response rows; missing values are excluded with counts. Scores are inverted to rank non-adherence, using AUROC and average precision without retuning thresholds. These are original dataset artifacts, not locally executed evaluator runs. Their software versions and precise prompts are not independently verified. This exploratory comparison does not influence primary selection.
